# field-notes

Hard-won operational notes from running personal infrastructure on free tiers (2026-10).
Each file documents one problem, what actually caused it, and the fix that worked.

- `zoho-catalyst-cli-sandbox.md` — making the Zoho Catalyst CLI log in inside a restricted sandbox
- `github-signup-email-policy.md` — which emails can register a GitHub account (verified the hard way)
- `sing-box-sfa-lessons.md` — sing-box for Android profile pitfalls
- `instabox-free-tier.md` — InstaBox free-tier limits and the keepalive pattern
- `pxxl-login-limits.md` — Pxxl "maximum accounts per device" and silent login bounces
- `freebuff-email-policy.md` — Freebuff rejects privacy/alias email providers for new accounts
- `ascs-emergency-ro.md` — "Running" in a panel does not mean the filesystem is writable
